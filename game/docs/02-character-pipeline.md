# 02. 캐릭터 파이프라인

"AI로 내 캐릭터 만들어서 넣는다"는 계획에 대한 현실적인 경로와, 넣은 뒤에
애니풍으로 보이게 만드는 기술적 단계를 정리합니다.

---

## 1. 먼저: AI로 3D 캐릭터를 바로 뽑는 건 아직 안 됩니다

이 부분을 먼저 솔직하게 말해두는 게 시간을 아껴줍니다.

Meshy, Tripo3D, Rodin, Hunyuan3D 같은 **text/image-to-3D** 도구는 2026년 기준으로도
플레이어블 애니 캐릭터를 못 만듭니다. 나오는 결과물의 문제:

- **리깅이 없습니다.** 본도 스킨 웨이트도 없는 단일 메쉬입니다. 애니메이션이 불가능합니다.
- **토폴로지가 쓸 수 없습니다.** 삼각형이 무작위로 흐릅니다. 셀셰이딩은 깔끔한 쿼드 흐름과
  의도된 법선에 전적으로 의존하는데, 그게 없으면 그림자 경계가 지저분하게 깨집니다.
- **텍스처에 조명이 구워져 있습니다.** 이미 그림자가 그려진 텍스처에 다시 셀셰이딩을
  올리면 그림자가 두 겹으로 보입니다.
- **얼굴이 뭉개집니다.** 애니 얼굴은 코가 거의 없고 눈이 거대한 비현실적 구조인데,
  이 도구들은 사실적 비율로 수렴합니다.

프롭(상자, 바위, 무기)에는 충분히 쓸 만합니다. 캐릭터에는 아닙니다.

## 2. 혼자서 실제로 가능한 경로

### 경로 A: VRoid Studio (강력 추천)

**[VRoid Studio](https://vroid.com/studio)** — 무료, 애니 캐릭터 전용 3D 모델러입니다.

왜 이게 정답인가:

- 처음부터 **애니 비율 등신** 베이스 메쉬로 시작합니다. 얼굴 구조 문제가 해결된 상태입니다.
- **휴머노이드 리그가 이미 들어 있습니다.** 본 이름이 표준이라 Unity Humanoid로 바로 잡힙니다.
- 머리카락을 **가이드라인을 그려서** 만듭니다. 판(plane) 기반 헤어 메쉬가 자동 생성됩니다.
- 얼굴/옷/머리 텍스처를 직접 그리거나 **외부 이미지를 가져올 수 있습니다.**
  ← **여기가 AI를 쓰는 지점입니다.**
- VRM으로 익스포트. 상업적 이용도 허용됩니다 (약관은 직접 한 번 확인하세요).

AI를 끼워넣는 방법:

1. **캐릭터 컨셉아트를 AI로 생성** — 정면/측면 설정화, 머리색, 눈, 교복 디자인.
   이게 AI가 실제로 압도적으로 잘하는 영역입니다.
2. VRoid에서 그 컨셉을 따라 모델링 (얼굴 파라미터 조정, 헤어 가이드 그리기)
3. **텍스처를 AI로 생성/보정** — 눈 텍스처, 옷 패턴, 소품. VRoid가 UV 템플릿을
   PNG로 내보내주니 그 위에 작업하면 됩니다.

캐릭터 하나에 **반나절~이틀**이면 됩니다. 외주 300만원 대신에요.

### 경로 B: AI 컨셉아트 → Blender 직접 모델링

시간이 아주 많거나 모델링을 배우고 싶을 때. 캐릭터 하나에 2~4주입니다. 혼자서 캐릭터
20명을 이 경로로 만드는 건 불가능합니다. 주인공 1~2명만 이렇게 하고 나머지는
경로 A로 가는 혼합 전략이 현실적입니다.

### 경로 C: 에셋 스토어 / Booth

Booth(booth.pm)에 VRM 아바타가 수천 개 있습니다. 개인용이면 그대로,
배포하려면 각 모델의 라이선스를 확인해야 합니다.

## 3. Unity로 가져오기

### VRM 임포트

1. **UniVRM** 설치: [github.com/vrm-c/UniVRM](https://github.com/vrm-c/UniVRM) 릴리스에서
   `.unitypackage`를 받아 임포트. (VRM 0.x와 VRM 1.0은 패키지가 다릅니다. VRoid 최신 버전은
   1.0으로 내보내니 `VRM-1.0` 패키지를 쓰세요.)
2. `.vrm` 파일을 `Assets/` 에 드래그. 프리팹이 생성됩니다.
3. 프리팹을 씬에 놓고 `Inspector` → `Animator` → `Avatar`가 Humanoid로 잡혔는지 확인.

### 툰 셰이더로 전환

VRM은 MToon 셰이더로 들어옵니다. 우리 셰이더로 바꿉니다.

1. 씬의 캐릭터 GameObject 선택
2. 메뉴 **Tools → BlueLike → Convert Selection To Toon Shader**

이 툴이 하는 일:

- 모든 머티리얼을 `BlueLike/AnimeToon`으로 전환하고 베이스맵/컬러를 보존
- 머티리얼 이름에 `hair`/`헤어`가 들어가면 `BlueLike/AnimeToonHair`로
- `face`/`얼굴`이 들어가면 `_IsFace = 1`로 세팅 (SDF 얼굴 그림자 활성화)
- `eye`/`iris`/`눈`이 들어가면 아웃라인 0 + 스페큘러 0 (눈에 검은 테두리 생기는 것 방지)

이름 규칙이 다르면 `ToonMaterialTools.cs`의 `HairHints` / `FaceHints` / `EyeHints`
배열에 본인 규칙을 추가하세요.

### 전투 유닛에 연결

`BattleUnit`이 붙은 GameObject에 `CharacterModelBinder`를 추가하고
`Model Prefab`에 캐릭터 프리팹을 넣습니다. 그게 전부입니다.

전투 코드는 메쉬를 전혀 모릅니다. 유닛 트랜스폼을 움직이고 `BattleUnit.Muzzle`만
읽습니다. 그래서 캡슐 → 실제 캐릭터 교체가 전투 로직 한 줄도 건드리지 않습니다.

`CharacterModelBinder`는 추가로:

- `Animator`를 찾아서 유닛 상태(`Idle`/`Move`/`Fire`/`Reload`/`ExSkill`/`Death`)에 맞춰
  `CrossFade`를 호출합니다. 없는 스테이트는 조용히 무시합니다.
- `Muzzle`이라는 이름의 트랜스폼을 찾습니다. 없으면 오른손 본을 씁니다.
  → 모델 안에 총구 위치에 빈 GameObject를 만들고 이름을 `Muzzle`로 하세요.
- `FaceDirectionBinder`를 자동으로 붙입니다 (아래 SDF 항목 참고).

## 4. 애니풍으로 보이게 만드는 기술 단계

모델을 넣기만 해서는 안 예쁩니다. 아래가 실제로 차이를 만드는 작업들입니다.
**중요도 순서**로 적었습니다.

### 4-1. 얼굴 법선 편집 (가장 중요, 생략 불가)

문제: 그냥 모델링한 얼굴에 빛을 쏘면 코 그림자가 얼굴 가운데를 가로질러 깨집니다.
아무리 좋은 셰이더를 써도 이걸 안 하면 못 봅니다.

해결: **구(sphere)의 법선을 얼굴 메쉬에 전사합니다.**

Blender에서:

1. 머리를 감싸는 크기의 **구(UV Sphere)**를 하나 만들고 머리 위치에 맞춥니다.
2. 얼굴 메쉬 선택 → `Modifier Properties` → `Add Modifier` → `Edit` → **Data Transfer**
3. `Source`를 그 구로 지정
4. **Face Corner Data** 체크 → `Custom Normals` 선택 → 매핑 방식 `Nearest Corner and Best Matching Normal`
5. `Object Data Properties` → `Normals` → **Auto Smooth** 켜기 (Blender 4.1+ 에서는
   Auto Smooth가 제거되었으니 `Shade Auto Smooth` 적용)
6. 모디파이어 Apply, 구는 삭제

이걸 하면 얼굴 음영이 구처럼 매끄럽게 한 덩어리로 흐릅니다. 코 그림자가 사라집니다.
VRoid 모델은 이 처리가 **이미 되어 있는** 경우가 많습니다 — 먼저 그냥 넣어보고
얼굴이 깨지는지 확인한 다음 필요하면 작업하세요.

### 4-2. SDF 얼굴 그림자

4-1을 하면 얼굴이 깨지지는 않지만, 대신 음영이 너무 평평해집니다. 원신/스타레일이
쓰는 방법은 **얼굴 그림자를 메쉬가 아니라 손으로 그린 맵으로 제어**하는 것입니다.

작동 원리:

- 얼굴 UV에 맞춘 그레이스케일 맵을 만듭니다.
- 각 픽셀의 값은 **"빛이 이만큼 돌아가면 나는 그림자에 들어간다"**는 임계값입니다.
- 셰이더(`AnimeToon.shader`의 `FaceLightTerm`)가 조명의 수평 각도를 머리의 forward/right
  벡터와 내적해서 임계값을 구하고, 맵 값과 비교합니다.
- 빛이 왼쪽에서 올 때는 UV를 좌우 반전해서 샘플링하므로 **맵 한 장으로 양쪽을 커버**합니다.

만드는 순서:

1. 메뉴 **Tools → BlueLike → Generate Face SDF Starter Map**
   → `Assets/BlueLike/Generated/FaceSDF_Starter.png` 생성 (단순 좌→우 그라데이션)
2. 이건 **출발점일 뿐입니다.** 실제 맵은 손으로 그려야 합니다:
   - 얼굴 UV를 깔고, 코 오른쪽 / 왼쪽 볼 / 눈 밑처럼 **먼저 그림자가 지는 영역을 어둡게**
   - 이마 중앙, 콧날처럼 **마지막까지 빛이 남는 영역을 밝게**
   - 그림자가 번지는 순서대로 밝기가 단조롭게 증가해야 합니다 (그게 SDF의 의미)
3. 얼굴 머티리얼에 `Face SDF Map`으로 할당, `Is Face Material` 체크
4. 캐릭터 루트에 `FaceDirectionBinder` 컴포넌트 (`CharacterModelBinder`가 자동으로 붙임)
   - `Head Bone`: 비워두면 Humanoid Animator에서 자동으로 찾습니다
   - `Forward Euler`: 모델 머리 본이 +Z를 안 보고 있으면 여기서 보정

> **이게 없으면 얼굴 그림자가 캐릭터가 돌아도 움직이지 않습니다.** `_FaceForward`와
> `_FaceRight`는 `FaceDirectionBinder`가 매 프레임 써주는 값입니다. 손으로 세팅하지 마세요.

이 단계는 솔직히 공들이는 작업입니다. 건너뛰고 진행해도 게임은 돌아갑니다
(맵이 없으면 흰색으로 샘플링돼서 그냥 평평한 조명이 됩니다). 나중에 하세요.

### 4-3. 머리카락 아니소트로픽 하이라이트

머리카락은 **절대 법선 기반 하이라이트를 쓰면 안 됩니다.** 머리카락은 가닥 다발이라
하이라이트가 가닥 방향을 **가로지르는 띠**로 나타납니다. 이 띠가 애니 머리카락을
만드는 결정적 요소입니다.

`AnimeToonHair.shader`가 Kajiya-Kay 모델로 처리합니다. 할 일:

1. 메뉴 **Tools → BlueLike → Generate Hair Jitter Map**
   → 가닥 방향 노이즈 맵 생성. 머리 머티리얼의 `Jitter / Shift Map`에 할당.
   이게 없으면 하이라이트가 플라스틱 링처럼 매끈하게 나옵니다.
2. `Strand Direction (UV)` 조정: 기본값 `(0,1,0,0)`은 UV의 V 방향으로 가닥이 흐른다고
   가정합니다. 머리 UV가 가로로 깔려 있으면 `(1,0,0,0)`으로.
3. `Primary Shift` / `Secondary Shift`로 띠를 머리 위아래로 슬라이드.
   Primary는 날카로운 흰 띠, Secondary는 넓고 부드러운 머리색 띠입니다.

### 4-4. 아웃라인

이미 셰이더에 들어 있습니다 (백페이스 확장). `Outline Width (px)`는 **픽셀 단위**라
카메라가 줌인/줌아웃해도 두께가 일정합니다.

부위별로 두께를 다르게 하고 싶으면:

- 머티리얼을 나누는 게 가장 간단합니다 (얼굴 0.8, 몸 1.2, 머리 1.0)
- 또는 Blender에서 **정점 컬러 알파**에 두께 배율을 칠하고 머티리얼의
  `Vertex Alpha Scales Width`를 켭니다. 손가락이나 얼굴 디테일에서 선이
  뭉치는 걸 잡을 때 이 방법을 씁니다.

눈, 입, 눈썹, 헤일로 머티리얼은 아웃라인 0으로 두세요.

### 4-5. 램프 텍스처

음영 단계를 더 정교하게 제어하려면:

1. 메뉴 **Tools → BlueLike → Generate Shadow Ramp Texture**
2. 머티리얼의 `Shadow Ramp`에 할당 + `Use Ramp Texture` 체크

생성되는 램프는 3단(코어 섀도우 / 미드톤 / 라이트)입니다. 포토샵에서 직접 수정해도
됩니다. 램프를 안 쓰면 `Shadow Steps`(1~4)로 단계 수를 조절합니다.

## 5. 모바일 예산

혼자 만들고 개인 기기에서만 돌릴 거라도, 폰에서 버벅이면 재미가 없습니다.

| 항목 | 목표 | 비고 |
|---|---|---|
| 캐릭터당 삼각형 | 15,000 ~ 30,000 | 화면에 10명이면 최대 30만 |
| 캐릭터당 머티리얼 | 2~4개 | 바디 / 얼굴 / 머리 / 눈. 많아지면 드로우콜이 곱으로 늘어남 |
| 텍스처 해상도 | 1024, 주인공만 2048 | VRoid 기본은 2048인데 1024로 줄이세요 |
| 본 개수 | 80개 이하 | 치마/머리 물리 본이 금방 늘어남 |
| Skin Weights | **2 bones** | Project Settings → Quality. 기본 4는 폰에서 낭비 |
| 아웃라인 패스 | 캐릭터만 | 배경 메쉬는 아웃라인 0으로 |

아웃라인은 메쉬를 **두 번** 그립니다. 즉 캐릭터 폴리곤 예산이 실질적으로 절반입니다.
이걸 계산에 넣으세요.

## 6. 옷/머리 물리

실제 클로스 시뮬은 폰에서 불가능합니다. 본 체인 + 스프링으로 합니다.

- **Magica Cloth 2** (유료, 에셋스토어) — 현재 Unity에서 가장 좋습니다. 치마 관통 처리가
  제대로 됩니다.
- **UniVRM의 VRMSpringBone** — VRM 모델에 이미 설정되어 있습니다. 무료, 머리카락에는 충분.
  치마는 약합니다.

VRoid에서 내보낸 모델은 머리카락 스프링본이 이미 세팅되어 있으니, 일단 그걸로
시작하고 부족할 때 Magica Cloth로 넘어가세요.
