## 1. 판매자 프로필

### 닉네임 후보 (하나 고르세요)
- 엑셀자동화연구소
- 반복업무끝
- 클릭한번랩
- 데이터정리공방

### 한 줄 소개
> 손으로 하던 엑셀·웹 반복 작업, 버튼 한 번으로 끝나게 만들어 드립니다

### 자기소개 (프로필 소개란)

안녕하세요, [닉네임]입니다.

매일 같은 엑셀을 열어서 복사하고, 붙여넣고, 합치고, 정리하는 일.
누군가는 매일 1시간씩 쓰고 있지만 한 번 자동화해 두면 클릭 한 번이면 끝나는 일입니다.

저는 이런 **반복 업무를 자동화하는 일**만 합니다.

**주로 하는 작업**
- 여러 엑셀 파일 합치기, 지점별·월별 매출 보고서 자동 집계
- 쇼핑몰 주문 엑셀 → 택배 송장 양식 변환
- 구글시트·구글폼·Gmail 연동 자동화 (Apps Script)
- 웹사이트 공개 데이터 수집해서 엑셀로 정리 (크롤링)
- 엑셀 매크로(VBA), Python 업무 도구 제작

**일하는 방식**
- 작업 전에 가능 여부와 견적을 먼저 솔직하게 말씀드립니다. 안 되는 건 안 된다고 합니다.
- 결과물과 함께 **처음 보는 사람도 따라 할 수 있는 사용법**을 드립니다.
- 납품 후 7일 동안 생긴 오류는 무료로 고쳐 드립니다.
- 보내주신 파일은 작업이 끝나면 삭제합니다. 개인정보를 지운 샘플 파일로도 작업할 수 있습니다.

아래 포트폴리오에서 실제로 만든 결과물을 확인해 보세요.
"이것도 자동화가 될까?" 싶은 작업이 있으면 편하게 물어봐 주세요.

### 전문 분야 / 보유 기술 태그
엑셀, 엑셀 매크로, VBA, 구글 스프레드시트, Google Apps Script, Python, pandas, 웹 크롤링, 데이터 정리, 업무 자동화

### 연락 가능 시간
> 매일 [09:00 ~ 23:00], 문의 주시면 [1시간] 안에 답변드립니다

## 2. 포트폴리오 등록 문구

이미지는 `kmong/images/` 폴더에 있습니다. 결과물 엑셀은 `kmong/portfolio/` 각 폴더의 `output/`에 있습니다.

### 포트폴리오 1 — 이미지: `portfolio-1-sales-report.png`
**제목**: 지점별 매출 엑셀 9개 → 통합 보고서 자동 생성

**설명**
3개 지점이 월마다 따로 보내는 매출 엑셀 9개를 실행 한 번으로 하나의 보고서로 합쳤습니다.
- 파일명에서 지점명을 자동으로 읽어서 구분
- 월별·지점별 매출표, 상품별 매출 순위, 지점별 일평균 매출 시트 자동 생성
- 막대 차트, 숫자 서식, 틀 고정까지 바로 보고할 수 있는 상태로 정리
- 다음 달에는 파일만 폴더에 넣고 다시 실행하면 끝

(샘플 데이터로 만든 예시입니다)

### 포트폴리오 2 — 이미지: `portfolio-2-shipping-label.png`
**제목**: 쇼핑몰 주문 엑셀 → 택배 송장 일괄등록 양식 자동 변환

**설명**
주문 내역을 택배사 송장 등록 양식으로 바꾸는 작업을 자동화했습니다.
- 같은 사람이 같은 주소로 여러 번 주문하면 한 상자(송장 1장)로 합치고, 같은 상품은 수량을 더함
- `+82 10…`, `010 1234 5678`처럼 제각각인 전화번호를 `010-1234-5678`로 통일
- 취소·반품 주문 자동 제외
- 주소가 빠진 주문은 별도 시트로 빼서 확인할 수 있게 표시

주문 30건 → 송장 10장, 오류 1건 자동 검출

(가상의 이름·연락처·주소로 만든 예시입니다)

### 포트폴리오 3 — 이미지: `portfolio-3-web-scraper.png`
**제목**: 웹사이트 50페이지 상품 정보 → 엑셀 자동 수집

**설명**
크롤링 연습용으로 공개된 도서 사이트에서 50페이지에 걸친 상품 1,000개의 정보를 모아 엑셀로 정리했습니다.
- 제목, 가격, 평점, 재고, 상품 링크 수집
- 평점·가격 순으로 정렬, 필터, 클릭하면 열리는 링크까지 적용
- 서버에 부담을 주지 않도록 요청 사이에 간격을 두고 수집

※ 공개된 데이터만, 사이트 이용약관을 지키는 범위에서 수집합니다.
