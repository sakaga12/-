# 크몽 상품글 초안

상품 2개를 동시에 올립니다. 리뷰가 없는 신규 계정이라 첫 주문을 받기 쉽게 가격을 낮게 잡았어요. 리뷰가 3~5개 쌓이면 가격을 올립니다.

---

## 상품 1. 엑셀·구글시트 업무 자동화

**카테고리**: IT·프로그래밍 > 업무 자동화 (없으면 "기타 프로그래밍")

**제목** (크몽 제목은 짧을수록 잘 보입니다)
> 엑셀, 구글시트 반복업무 자동화해 드립니다

**대표 이미지 문구**
> 매일 1시간 걸리던 엑셀 작업, 버튼 한 번으로
> 당일 상담 · 빠른 납품 · 수정 보장

### 서비스 설명

매일, 매주 반복하는 엑셀·구글시트 작업이 있으신가요?
복사-붙여넣기, 파일 합치기, 보고서 정리처럼 손으로 하던 일을 자동으로 처리되게 만들어 드립니다.

**이런 작업을 해드립니다**
- 여러 엑셀 파일을 하나로 합치기, 시트별로 나누기
- 매출·재고·주문 데이터 자동 집계와 보고서 생성
- 구글시트 ↔ 구글폼, Gmail 연동 (응답 오면 자동 정리·메일 발송)
- 조건에 맞는 데이터 자동 분류, 중복 제거, 서식 정리
- 복잡한 수식 정리, 대시보드 만들기
- 버튼 한 번으로 실행되는 매크로(VBA), Apps Script, Python 스크립트

**작업 방식**
1. 문의할 때 지금 하시는 작업을 설명하고 샘플 파일을 보내주세요 (실제 개인정보는 지운 파일이면 됩니다)
2. 가능 여부, 가격, 일정을 먼저 안내해 드립니다
3. 작업물과 사용법 설명서를 함께 드립니다
4. 실제 파일로 써보시고 안 맞는 부분은 패키지별 횟수 안에서 수정해 드립니다

**이런 분께 추천합니다**
- 엑셀 작업 때문에 매일 야근하는 실무자
- 직원 없이 주문·재고를 직접 관리하는 사장님
- 매크로가 필요한데 어디에 물어볼지 모르는 분

### FAQ

**Q. 제 작업도 자동화가 되는지 모르겠어요.**
A. 작업 순서를 대충 적어서 보내주시면 무료로 가능 여부를 판단해 드립니다. 안 되는 작업이면 솔직하게 말씀드립니다.

**Q. 회사 파일이라 보안이 걱정돼요.**
A. 이름, 연락처 같은 실제 데이터는 가짜 값으로 바꾼 샘플 파일로도 충분히 작업할 수 있습니다. 작업이 끝난 파일은 삭제합니다.

**Q. 맥에서도 되나요?**
A. 구글시트(Apps Script)나 Python으로 만들면 맥, 윈도우 모두 됩니다. VBA 매크로는 윈도우 엑셀 기준입니다. 문의할 때 사용 환경을 알려주세요.

**Q. 나중에 데이터 형식이 바뀌면요?**
A. 납품 후 7일 안에 생긴 오류는 무료로 고쳐드립니다. 기능 추가는 따로 견적을 드립니다.

### 구매자 요청사항 (주문할 때 받는 질문)
1. 지금 손으로 하시는 작업 순서를 적어주세요
2. 샘플 파일을 첨부해 주세요 (개인정보는 지워주세요)
3. 사용 프로그램: 엑셀(윈도우/맥) / 구글시트
4. 원하는 납품일

## 상품 2. 웹 데이터 수집(크롤링) 프로그램

**카테고리**: IT·프로그래밍 > 크롤링·스크래핑

**제목**
> 원하는 웹사이트 데이터 엑셀로 수집해 드립니다

**대표 이미지 문구**
> 일일이 복사하지 마세요
> 상품·가격·리뷰·목록 데이터를 엑셀로 한 번에

### 서비스 설명

웹사이트에 있는 정보를 하나하나 복사해서 엑셀에 옮기고 계신가요?
원하는 데이터를 자동으로 모아서 엑셀/CSV 파일로 정리해 드립니다.

**이런 데이터를 모아드립니다**
- 쇼핑몰 상품명, 가격, 옵션, 판매 수
- 부동산·채용·공공 사이트 목록 데이터
- 뉴스·게시판 글 목록, 키워드 모니터링
- 경쟁사 가격 변동 주기적 확인

**납품 방식은 두 가지입니다**
- **데이터만 납품**: 수집한 엑셀 파일을 드립니다
- **프로그램 납품**: 직접 돌릴 수 있는 프로그램과 사용법을 드립니다. 필요할 때마다 최신 데이터를 받을 수 있습니다

**작업 원칙**
- 누구나 볼 수 있는 공개 데이터만 수집합니다
- 로그인 우회, 개인정보 수집, 사이트 이용약관이나 robots.txt에서 금지한 수집은 하지 않습니다
- 상대 서버에 부담이 가지 않게 속도를 조절해서 수집합니다

### FAQ

**Q. 아무 사이트나 다 되나요?**
A. 사이트 구조에 따라 다르고, 약관상 수집을 금지한 곳이나 로그인해야 보이는 개인정보는 하지 않습니다. 주소를 보내주시면 가능 여부를 먼저 확인해 드립니다.

**Q. 사이트가 바뀌면 프로그램이 멈추나요?**
A. 사이트 화면 구조가 바뀌면 수정이 필요할 수 있습니다. 납품 후 7일 안에 생긴 오류는 무료로 고쳐드립니다.

**Q. 프로그래밍을 몰라도 쓸 수 있나요?**
A. 더블클릭이나 버튼 한 번으로 실행되게 만들고 화면 캡처가 들어간 사용법을 함께 드립니다.

### 구매자 요청사항
1. 수집할 사이트 주소
2. 원하는 항목 (예: 상품명, 가격, 링크)
3. 데이터만 필요하신지, 프로그램이 필요하신지
4. 원하는 납품일
